# أكاديمية رشيد

مشروع تعليمي مستقل يقدم:
- القرآن الكريم والعلوم الشرعية والعربية لغير الناطقين بها.
- التعليم الأهلي السعودي.
- التعليم العالمي السعودي.
- التعليم المصري العام والأزهري.
- متابعة مادة واحدة أو عدة مواد، والجمع بين أكثر من برنامج.

- الموقع الرئيسي: `index.html`
- التسجيل: `register.html`
- تطبيق PWA مستقل: `manifest.webmanifest` و`sw.js`
